# SaborNow — pacote estático

Este pacote contém a homepage completa do SaborNow pronta para hospedagem estática.

## Como publicar

1. Extraia o arquivo ZIP.
2. Envie **todos os arquivos e a pasta `assets`** para a mesma pasta pública da hospedagem.
3. Mantenha `index.html`, `styles.css`, `app.js` e `assets/` no mesmo nível.
4. Abra o domínio normalmente; não é necessário Node.js, banco de dados ou configuração especial.

A página já possui layout responsivo para desktop, tablet e celular. O formulário da newsletter funciona como interação visual no front-end; para armazenar e-mails em produção, conecte-o a um serviço de formulários ou backend.
