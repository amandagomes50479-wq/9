# SaborNow — pacote estático para hospedagem

Este pacote contém a homepage, imagens locais, JavaScript, páginas institucionais, `robots.txt` e `sitemap.xml`.

## Como publicar

1. Extraia o ZIP.
2. Envie todos os arquivos e a pasta `assets` para a pasta pública da hospedagem.
3. Mantenha `index.html`, `styles.css`, `app.js` e `assets/` no mesmo nível.
4. Abra `contato.html` e substitua o texto pelos dados reais do responsável pelo domínio.
5. Abra `robots.txt` e `sitemap.xml` e troque `https://SEU-DOMINIO.com.br` pelo domínio real.
6. Ative HTTPS e confirme que o anúncio abre exatamente a mesma página para todos os visitantes.

O pacote não possui redirecionamentos automáticos, cloaking, pop-ups, scripts de rastreamento, malware ou código de burlar revisão. O formulário da newsletter é visual e só deve ser conectado a um serviço depois que a política de privacidade for atualizada.

A limpeza do pacote não remove uma suspensão da conta Google Ads nem corrige uma invasão na hospedagem. Antes de anunciar, verifique o domínio no Search Console, no relatório de problemas de segurança e no Google Safe Browsing.
